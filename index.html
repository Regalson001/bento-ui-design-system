What is Bento UI?

Bento UI is a modern component library built using HTML5 and CSS3, demonstrating reusable design patterns and responsive layouts.

Does it require JavaScript?

The included interactions use native browser controls and CSS. No JavaScript is required for the demonstrated components.

Can I customise the components?

Yes. Colours, spacing, borders, typography and component states are managed through reusable CSS variables and component classes.
